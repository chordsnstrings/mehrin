# Manrope

Unmodified variable font from the [Google Fonts Manrope directory](https://github.com/google/fonts/tree/main/ofl/manrope).

- Upstream file: `Manrope[wght].ttf`
- Git blob: `23dcf5e05a97f19a3567d40ebb3765580a4325f7`
- Weight range: 200–800
- License: SIL Open Font License 1.1; see `OFL.txt`.

The app preloads and caches this local asset for consistent typography online and offline. Use a new asset path if replacing the font bytes so installed service workers cannot serve an earlier font under the same URL.
